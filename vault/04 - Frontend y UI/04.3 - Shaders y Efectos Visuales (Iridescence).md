# 🌊 Shaders y Efectos Visuales — Iridescence (WebGL / OGL)

El fondo dinámico del portal está impulsado por el componente **`Iridescence`**, una implementación de shader GLSL de alta fidelidad renderizado mediante la biblioteca **OGL**.

---

## 1. Funcionamiento Matemático del Fragment Shader
El shader genera ondas de seda líquida e iridiscencia mediante la acumulación armónica de funciones trigonométricas no lineales:

```glsl
precision highp float;

uniform float uTime;
uniform vec3 uColor;
uniform vec3 uResolution;
uniform vec2 uMouse;
uniform float uAmplitude;
uniform float uSpeed;

varying vec2 vUv;

void main() {
  float mr = min(uResolution.x, uResolution.y);
  vec2 uv = (vUv.xy * 2.0 - 1.0) * uResolution.xy / mr;

  uv += (uMouse - vec2(0.5)) * uAmplitude;

  float d = -uTime * 0.5 * uSpeed;
  float a = 0.0;
  for (float i = 0.0; i < 8.0; ++i) {
    a += cos(i - d - a * uv.x);
    d += sin(uv.y * i + a);
  }
  d += uTime * 0.5 * uSpeed;
  vec3 col = vec3(cos(uv * vec2(d, a)) * 0.6 + 0.4, cos(a + d) * 0.5 + 0.5);
  col = cos(col * cos(vec3(d, a, 2.5)) * 0.5 + 0.5) * uColor;
  gl_FragColor = vec4(col, 1.0);
}
```

### Explicación de Variables:
1. `uTime`: Temporizador de precisión en milisegundos (`performance.now() * 0.001`).
2. `uSpeed`: Factor de velocidad temporal (`0.85` configurado para un movimiento armónico, ni lento ni acelerado).
3. `uColor`: Vector RGB normalizado `[0.0 - 1.0]` que tiñe las ondas.
4. `uResolution`: Resolución de pantalla para mantener la relación de aspecto sin deformaciones en monitores ultra-wide o pantallas móviles.
5. `mouseReact: false`: Desactivado por solicitud del usuario para que el movimiento del ratón no perturbe la calma del fondo.

## 2. Paleta Cromática Aplicada
A diferencia de configuraciones genéricas, el color se sintoniza con la identidad de la institución:
- **Modo Claro:** `color={[0.05, 0.48, 0.92]}` con opacidad CSS al `56%` sobre fondo claro. Genera ondas celestes, cian ártico y azul real de aspecto fresco y pulcro.
- **Modo Oscuro:** `color={[0.10, 0.68, 1.0]}` con opacidad CSS al `95%` sobre negro profundo. Produce un resplandor bioluminiscente de alta energía.
- **Libre de Amarillos:** Se eliminaron por completo las frecuencias cálidas para mantener la pureza del contraste azul/cian.

---

## 3. Actualización de Uniforms sin Fugas de Memoria
En `Iridescence.tsx`, cuando el usuario alterna el tema, los uniforms se actualizan directamente en la memoria GPU sin recrear el contexto WebGL:

```typescript
useEffect(() => {
  if (programRef.current) {
    programRef.current.uniforms.uColor.value.set(color[0], color[1], color[2]);
    programRef.current.uniforms.uSpeed.value = speed;
    programRef.current.uniforms.uAmplitude.value = amplitude;
  }
}, [color, speed, amplitude]);
```
