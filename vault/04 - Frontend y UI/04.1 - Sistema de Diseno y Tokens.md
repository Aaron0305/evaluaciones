# 🎨 Sistema de Diseño y Tokens

El sistema de diseño de **What Time Is It? Idiomas** está construido con **Tailwind CSS v4** y variables nativas de CSS en `globals.css`, permitiendo un cambio de tema (*theming*) impecable entre **Modo Claro** y **Modo Oscuro**.

---

## 2. Curvas de Animación de Alta Gama (Emil Kowalski Physics)
Para garantizar que el software se sienta natural, orgánico y con respuesta física real, se utilizan curvas cúbicas de Bézier no lineales:

```css
--ease-out-expo: cubic-bezier(0.23, 1, 0.32, 1);       /* Respuesta inmediata para UI */
--ease-in-out-smooth: cubic-bezier(0.77, 0, 0.175, 1); /* Movimiento orgánico en pantalla */
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);        /* Física elástica estilo Apple */
```

---

## 3. Clases de Utilidad Especializadas
- **`.glass-card`**: Proporciona el efecto de vidrio esmerilado con desenfoque de fondo profundo:
  ```css
  .glass-card {
    background: var(--surface);
    backdrop-filter: blur(28px) saturate(190%);
    -webkit-backdrop-filter: blur(28px) saturate(190%);
    border: 1px solid var(--surface-border);
    box-shadow: var(--card-shadow), inset 0 1px 1px 0 rgba(255, 255, 255, 0.6);
  }
  ```
- **`.btn-press`**: Simula física mecánica al presionar cualquier botón interactivo (`transform: scale(0.97)` en estado `:active`).
- **`.noise-overlay`**: Capa fija de grano cinematográfico analógico al 2.5% de opacidad para eliminar el escalonamiento de degradados (*color banding*).
