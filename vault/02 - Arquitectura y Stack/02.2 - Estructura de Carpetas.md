# 📁 Estructura de Carpetas del Proyecto

El proyecto sigue una arquitectura limpia basada en responsabilidades claras (*Separation of Concerns*), separando la capa de presentación, layout, componentes reutilizables y utilidades.

```text
evaluacion/
├── .agents/                    # Reglas de desarrollo y skills del asistente inteligente
│   ├── rules/                  # Reglas Clean Code y UI/UX Design
│   └── skills/                 # Skills especializados (animate, apple-design, etc.)
├── public/                     # Activos estáticos públicos servidos por Next.js
│   └── image/                  # Logotipos institucionales y arte de la mascota
│       ├── logo.png            # Logo horizontal principal
│       ├── logo_mensaje.png    # Isotipo cuadrado para tarjetas
│       └── mascota_hde.png     # Render de alta definición de la mascota
├── src/                        # Código fuente de la aplicación
│   ├── app/                    # Next.js App Router (Rutas, Layouts, Estilos globales)
│   │   ├── favicon.ico         # Ícono de pestaña del navegador
│   │   ├── globals.css         # Tokens CSS, variables de diseño, glass-card y utilidades
│   │   ├── layout.tsx          # Layout raíz (Navbar, ThemeProvider, Footer, Fuentes)
│   │   ├── page.tsx            # Página de inicio (renderiza LoginView)
│   │   └── login/
│   │       └── page.tsx        # Ruta dedicada /login con metadatos SEO
│   └── components/             # Componentes modulares reutilizables
│       ├── auth/               # Componentes del módulo de autenticación
│       │   ├── LoginForm.tsx   # Tarjeta de formulario con estados, validación y glassmorphism
│       │   └── LoginView.tsx   # Vista integrada (Mascota + Diálogo + Formulario)
│       ├── layout/             # Componentes de estructura global
│       │   ├── Navbar.tsx      # Barra de navegación con scroll adaptativo y frosted glass
│       │   └── Footer.tsx      # Pie de página minimalista institucional
│       ├── ui/                 # Componentes gráficos y de experiencia de usuario
│       │   ├── AnimatedBackground.tsx # Orquestador del fondo animado
│       │   ├── Iridescence.tsx # Motor de shader WebGL OGL para ondas de seda líquida
│       │   └── ThemeToggle.tsx # Botón interactivo de cambio de modo claro/oscuro
│       └── theme-provider.tsx  # Wrapper de next-themes para hidratación limpia de tema
├── vault/                      # Bóveda de documentación en formato Obsidian
├── package.json                # Declaración de dependencias y scripts de ejecución
├── tsconfig.json               # Configuración de compilación estricta de TypeScript
└── postcss.config.mjs          # Configuración del pipeline de procesamiento CSS
```

---

## 2. Convenciones de Ubicación
- **Componentes de Negocio / Vistas:** `src/components/{modulo}/` (ej. `auth/`).
- **Componentes Estructurales:** `src/components/layout/` (ej. `Navbar.tsx`, `Footer.tsx`).
- **Componentes Visuales Puros / Primitivas:** `src/components/ui/` (ej. `Iridescence.tsx`, `ThemeToggle.tsx`).
- **Páginas de Enrutamiento:** `src/app/{ruta}/page.tsx` (con Server Components como envoltorio y metadatos SEO).
