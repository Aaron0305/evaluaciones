# ⚡ Stack Tecnológico

El proyecto está edificado sobre el estado del arte del ecosistema JavaScript / TypeScript para la web, garantizando velocidad de ejecución, compilación instantánea y una experiencia visual de 60 FPS.

---

## 1. Núcleo del Frontend y Servidor
| Tecnología | Versión | Rol en el Proyecto |
| :--- | :--- | :--- |
| **Next.js** | `16.3.5` | Framework Fullstack con App Router, Server Components y compilación por Turbopack. |
| **React** | `19.2.8` | Biblioteca de interfaces con soporte para hooks modernos, transiciones y renderizado concurrente. |
| **TypeScript** | `5.9.3` | Tipado estricto en todo el código, previniendo errores en tiempo de desarrollo. |
| **pnpm** | `10.26.0` | Gestor de paquetes ultrarrápido y eficiente con enlaces duros (*hard links*). |

---

## 2. Estilizado y Gráficos
| Biblioteca | Versión | Rol en el Proyecto |
| :--- | :--- | :--- |
| **Tailwind CSS** | `v4.3.3` | Motor de CSS de alto rendimiento sin configuración tradicional (`@theme inline`), integrado con PostCSS. |
| **OGL** | `1.0.11` | Biblioteca WebGL minimalista y de altísima velocidad para shaders GLSL interactivos en el fondo. |
| **Lucide React** | `1.46.0` | Iconografía vectorial SVG moderna, ligera y coherente. |
| **next-themes** | `0.4.6` | Gestión fluida de temas Claro/Oscuro sin parpadeos de renderizado (*FOUC*). |
| **clsx & tailwind-merge** | Reciente | Composición segura y sin colisiones de clases condicionales de Tailwind. |

---

## 3. Ventajas Clave del Stack
1. **Turbopack:** Tiempos de Hot Reload menores a 50ms en desarrollo.
2. **WebGL Nativo (OGL):** Aceleración directa por GPU para los shaders de ondas, con consumo mínimo de CPU y batería.
3. **Cero Dependencias Pesadas:** Se evitó el uso de bibliotecas 3D sobrecargadas (como Three.js de 600KB+), logrando que el bundle final sea sumamente ligero.
